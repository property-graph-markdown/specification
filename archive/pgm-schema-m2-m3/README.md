# Archived PGM Schema M2/M3 Variant

This directory preserves the former three-level `M1 → M2 → M3` design for
historical reference. It is not the canonical PGM schema and is deliberately
stored outside `pgm-schema/`, so Obsidian and the PGM plugin do not index its
same-named definition nodes as part of the active vault.

The archived Markdown files retain the model structure from the point at which
the variant was retired. They may contain incomplete or inconsistent links and
are not covered by the active schema validator.

The canonical model is now the reflexively closed
[`M2*`](../../pgm-schema/M2*/Node_Label.md) meta-ontology. Its complete M1
example is located in [`pgm-schema/M1`](../../pgm-schema/M1/Person.md).
