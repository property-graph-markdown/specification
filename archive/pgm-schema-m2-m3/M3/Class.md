# Class

`Class` classifies Class definitions as well as its own definition node. Therefore, `type(M3/Class) = M3/Class` holds reflexively. [:Class {"symbol":"Class"}]()

A Class is a specialized classifier.

A Class may derive from another Class.

A Class may own Attribute definitions. [:HAS_ASSOCIATION](HAS_ATTRIBUTE.md)

A Class may own Association definitions. [:HAS_ASSOCIATION](HAS_ASSOCIATION.md)
