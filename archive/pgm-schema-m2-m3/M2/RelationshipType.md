# Relationship

`Relationship` classifies M1 definitions of directed domain Relationship Types. [:Class {"symbol":"Relationship"}]()

A Relationship Type is a Property Owner.

A Relationship definition has its domain Type identifier. [:HAS_ATTRIBUTE](M2/identifier.md)

A Relationship definition refers to its Target Node Type. Its Source domain is determined by the M1 Node Type that owns it through `HAS_RELATIONSHIP`. [:HAS_ASSOCIATION](M2/HAS_RANGE.md)
