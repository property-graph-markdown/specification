# HAS_PROPERTY

`HAS_PROPERTY` assigns a Property Key definition to a Node Label or Relationship Type definition. [:Relationship_Type {identifier: "HAS_PROPERTY"}]()

The permitted Source domain is determined by the definitions that declare `HAS_PROPERTY` through `HAS_RELATIONSHIP`. In this model, these are `Node_Label` and `Relationship_Type`.

The Range is `Property_Key`. [:HAS_RANGE](Property_Key.md)
