# Relationship_Type

`Relationship_Type` classifies definitions of directed domain Relationship Types. [:Node_Label {identifier: "Relationship_Type"}]()

A Relationship Type definition has a stable identifier. [:HAS_PROPERTY](identifier.md)

A Relationship Type definition may have Property Key definitions. [:HAS_RELATIONSHIP](HAS_PROPERTY.md)

A Relationship Type definition refers to its Target Node Label. Its Source domain is determined by the Node Label definition that owns it through `HAS_RELATIONSHIP`. [:HAS_RELATIONSHIP](HAS_RANGE.md)
