# Node_Label

`Node_Label` classifies domain Node Label definitions as well as its own definition node. Therefore, `type(Node_Label) = Node_Label` holds reflexively. [:Node_Label {identifier: "Node_Label"}]()

A Node Label definition has a stable identifier. [:HAS_PROPERTY](identifier.md)

A Node Label definition may have Property Key definitions. [:HAS_RELATIONSHIP](HAS_PROPERTY.md)

A Node Label definition may have Relationship Type definitions. [:HAS_RELATIONSHIP](HAS_RELATIONSHIP.md)
