# HAS_RANGE

`HAS_RANGE` assigns its permitted Target Node Label to a Relationship Type definition. [:Relationship_Type {identifier: "HAS_RANGE"}]()

The Domain is established by the declaration on `Relationship_Type`.

The Range is `Node_Label`. This definition uses `HAS_RANGE` itself and therefore remains closed within M2*. [:HAS_RANGE](Node_Label.md)
